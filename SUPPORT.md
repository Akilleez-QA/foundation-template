# Support

- Questions and problems: open a GitHub issue with the [problem report](.github/ISSUE_TEMPLATE/problem-report.md) template. Include the command you ran, the output and the commit.
- Feature or interface changes: use the [change request](.github/ISSUE_TEMPLATE/change-request.md) template.
- Security issues: report privately as described in [SECURITY.md](SECURITY.md).
- Commercial licensing questions go to craig@nh3.biz.

Before asking, check the [troubleshooting table](docs/guides/how-to/README.md#troubleshooting).
